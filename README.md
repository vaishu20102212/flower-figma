# 🌸 FLOWER — Modern Dashboard & Admin UI

A complete, high-fidelity responsive React + Tailwind CSS dashboard application designed from the **FLOWER UI Kit** Figma design.

## ✨ Modules Included

1. **Overview Dashboard (`/`)**
   - KPI metrics (Income, Sales, Clients)
   - Dual Bar Chart (Income vs Expense) with hover tooltips
   - Analytics Spline Curve Area Chart
   - Sales Donut Gauge & Bidirectional Horizontal Statistics Chart
   - Last Orders Table & Live Transactions Timeline

2. **E-Commerce Products (`/products`)**
   - Products listing table with multi-select checkboxes
   - Filter tabs (`All`, `Available`, `Disabled`), Search, List/Grid switchers
   - Product details modal with specifications, quantity counter, and cart action

3. **E-Commerce Orders (`/orders`)**
   - Order management with real-time status badges (`Shipped`, `Processing`, `Cancelled`)
   - Order details drawer and shipment tracker

4. **Calendar (`/calendar`)**
   - Month, Week, and Day views
   - Category color filters (`Meeting`, `Event`, `Work`, `Important`, `Other`)
   - Add event modal dialog

5. **Mail (`/mail`)**
   - 3-Column email interface (Folders/Labels, Feed, Reader with attachments)
   - Rich quick-reply formatting composer and compose modal

6. **Task Kanban Board (`/tasks`)**
   - `TODO`, `IN PROGRESS`, and `COMPLETED` columns
   - Subtasks checklist with progress bars, image previews, and team avatars

7. **Projects (`/projects`)**
   - Project cards with milestone progress bars, deadlines, and team stacks

8. **File Manager (`/files`)**
   - Cloud storage meter (75.4 GB / 100 GB used)
   - Folder categories and recent files list/grid view with download buttons

9. **Social & Chat (`/chat`, `/contacts`, `/notes`)**
   - Live interactive chat interface with contacts list and messaging
   - Contacts directory and Notes management

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
